# Pocket Planner — Releases

This repository is dedicated to hosting the compiled distribution binaries, installers, and auto-update metadata for **Pocket Planner**, a minimal desktop application for weekly task planning and daily check-ins.

## Download & Installation

To download the latest version of Pocket Planner for your operating system (Windows or macOS), please visit the [Releases Page](https://github.com/pocket-planner/desktop-app-releases/releases/latest).

- **Windows**: Download the `.exe` installer.
- **macOS**: Download the `.dmg` package.
